Render Free Web services use public `onrender.com` hostnames. Internal HTTP routes retain service-key protection, and Mobile contains no service secret. The Free Postgres candidate uses separate service-owned logical databases; shared database credentials are not a production isolation boundary. Never add a verification bypass.

EAS injects `EXPO_PUBLIC_*` values into the client bundle; these values must be public URLs only. No access tokens, service keys, database URLs, or provider secrets may use that prefix.
