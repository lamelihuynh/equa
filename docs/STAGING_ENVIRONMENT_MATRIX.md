Free Render Web services use public `onrender.com` hostnames, so service URLs are not private. JWTs protect user routes and service keys protect internal routes. The three application databases use the same managed Postgres default credential in this demo Blueprint; each service targets only its own logical database. This is not production-grade database-user isolation.

Never place actual values or API keys in this document. Identity verification is not bypassed when Resend is unavailable.
